# TUI slash 指令展示方案

> Historical archive / 历史归档：本文记录旧设计或一次性验证，不是当前接口合同，也不代表本次重构已通过验收。当前设计见 [Research Memory plan](../RESEARCH_MEMORY_DESIGN_AND_IMPLEMENTATION_PLAN.zh-CN.md)。

状态：代码已实现并完成本地验证，尚未部署到日常使用的安装目录。参考用户提供的 Codex Experimental features 面板。设计预览使用示例数据。

## 目标与当前问题

让用户立即区分普通对话、工具执行输出和 slash 命令交互。统一标题、背景、选择状态、反馈与键盘提示，同时保留现有命令行为。

当前 `/usage`、`/research`、`/sys-prompt` 已通过 `showDocument` 打开独立文档组件，但 `tspi-document-view.mjs` 只画标题、正文与翻页提示。Pi 选择器单独拼装标题与 SelectList，短反馈则通过 showStatus 使用 dim 文本。三条路径缺少一致的视觉边界。`/research` 还主要使用通用对象格式化，内容层级与普通文本难以区分。

## 统一展示规则

| Before | After | Why |
| --- | --- | --- |
| 文档页仅标题加正文 | 独立背景，顶部 `/命令 · 标题`、只读标记与范围说明，底部固定快捷键 | 识别命令来源、作用范围及交互状态 |
| 选择器与文档页分别布局 | 同一面板外壳；蓝色整行高亮、`›` 光标和“当前”标记 | 区分当前焦点与已生效选项，弱色彩终端仍可理解 |
| 短反馈是灰色散文 | 带 `/命令` 和状态符号的紧凑反馈条 | 与助手答复、运行状态区分 |
| 研究状态通用对象展开 | 按目标、节点、执行与研究状态展示摘要；详情保留完整阅读入口 | 先展示用户需要判断的信息 |

借鉴截图的整块底色、标题与说明层次、整行选择和快捷键栏。正文保持正常字重，不采用低对比度说明文字，也不给所有面板强加复选框。

面板位于当前输入区域，保留上方对话上下文；打开时取得键盘焦点。默认使用现有主题的深蓝灰色系，选中行使用明显的蓝色填充和深色前景。新增面板语义色集中在展示层映射，不能直接给全局 customMessageBg 改色，避免连带改变聊天输出。单色模式以分隔线、标题、`›` 和“当前”标记区分。

## 命令覆盖

| 类型 | 当前命令 | 展示与交互 |
| --- | --- | --- |
| 单选 | `/model`、`/thinking`、`/resume` | ↑↓ 移动，Enter 应用，Esc 取消；移动光标不写配置；成功后关闭并显示反馈条 |
| 阅读 | `/usage`、`/sys-prompt`、`/research` 子命令 | 固定标题与页码；↑↓ 按行滚动，PgUp/PgDn 翻页，Home/End 跳转，Esc 返回；延续现有左右翻页习惯 |
| 操作 | `/compact`、`/reload` | 同一位置显示进行中、成功或失败，保留命令名；关闭展示不等同于取消已经提交的操作 |
| 退出 | `/quit` | 保留退出当前终端的行为；不弹无意义的空面板 |
| 无效输入 | 未知命令、参数错误 | 命令错误条与正确用法；避免灰色提示混入普通输出 |

以后若新增多选设置页，再使用 `[ ]/[x]` 与 Space 切换、Enter 保存、Esc 放弃；不把截图的“Esc 保存”套到所有命令，也不为了样式新增业务命令。

## 交互约束

- 只有一个活动命令面板。命令打开后立即呈现标题和加载状态；失败与空结果留在同一块区域，避免跳成无来源的普通文本。
- 键盘操作立即响应，不加进出动画。页脚只列真实支持的快捷键；阅读页不显示保存，单选页不显示 Space 勾选。
- 保存打开面板前的编辑器状态，返回后恢复光标和草稿；已提交的 slash 命令不重新放回编辑器。面板内按 Enter 不应意外发送聊天消息。
- 模型继续输出或 Monitor 更新时，面板焦点与阅读位置不被抢走；关闭面板后恢复聊天。进行中的模型/Job 不因关闭面板而被取消。
- 标题、说明、正文、快捷键占用行数统一计算；按终端单元格宽度处理中文、ANSI、组合字符和长 ID。窄屏将说明列放到下一行，不把关键标识截到无法判断。
- 加载请求绑定会话与面板实例。关闭、切换会话或断连后，迟到响应不得重新打开旧面板；重绘不能把选择移回已生效项。
- 阅读与选择过程保持在 presentation，不写入模型 transcript；命令实际引起的模型配置、压缩、会话切换等操作继续通过原服务执行。
- 成功反馈可短暂显示；错误保留至关闭或下一条命令。普通工具输出、模型答复和 slash 反馈使用不同的外壳。

## 实现顺序

1. **统一外壳。** 在 TSPi presentation 层实现 CommandPanel，复用现有文档分页、主题和宽度处理；负责标题、范围、正文容器、状态与快捷键。
2. **接入三条展示路径。** 将 showDocument、select、showStatus 接到统一展示机制。命令执行入口传递来源命令与展示实例身份，避免按标题或消息字符串猜测来源。Pi 的 model/thinking/compact/reload 与 TSPi 命令一并覆盖；不改命令执行服务。
3. **优化内容与生命周期。** `/research` 提供面向阅读的摘要；`/usage` 分组显示计数；`/sys-prompt` 保留完整文本与来源。补齐加载、空结果、失败、失联、关闭和焦点恢复。修改 Pi 的地方继续走仓库固定版本补丁与校验流程，不只编辑测试 checkout。
4. **验收真实终端。** 检查完整命令清单；使用当前 pinned Pi、真实 Native TUI 与独立安装包验证。

## 验收

- 80×24、120×30、较窄与较矮终端下，标题和必要快捷键可见，内容不越界；中文与超长 ID 不错位。
- 同一命令的正常、加载、无结果和失败状态具有同一视觉归属。
- ↑↓/Enter/Esc、翻页、缩放、后台流式输出、Monitor 更新与会话切换均不破坏选择、滚动位置或草稿。
- 当前选择和光标焦点同时可辨认；关闭未提交的选择不会改变模型或会话。
- 关闭后的迟到响应不会重新显示；纯浏览不会新增模型请求或 transcript 记录。
- 固定版本补丁校验、Native 命令/文档测试及真实 TUI 按键集成通过；至少人工检查一次深色和单色展示。

该方案仅涉及终端展示；计算语义去重属于独立的领域扩展工作。
