# 过渡态验证

过渡态验证把程序完成、驻点证据、振动模式归属、结构身份 与科学解释分开。任何单一
解析器标记都不能同时建立这些结论。

[Gaussian runner](../../gaussian/SKILL.zh-CN.md) 使用 `gaussian_io.py::parse_log` 写出
`parsed.json`，提取终止、收敛、驻点标记、频率、几何及最终谐振表的笛卡尔模式向量。
其 `section_index` 参数从零开始。选择相关 section，并把输出 route、电荷、多重度、
方法和基组与输入比较。
后续未完成的优化或谐振段不继承此前通过的证据；收敛需要最终优化表中的完整四项记录。

对经典一阶鞍点，要求优化收敛，并存在一个表示所提出基元步骤的虚频模式。数值噪声、约束、
平坦模式与竞争虚频必须保持可见。检查位移向量，不能只依赖虚频数量。

以当前研究假设定义相关位移：可以是成键、断键、质子转移、重排或其他反应坐标，
不能预设必须有两条成键或要求所有反应具有同一种协同运动。比较模式正、负方向的扰动几何，
结合关键内坐标变化判断模式是否对应目标步骤；模式整体正负号本身没有物理区别。

选择脚本前核对其适用范围。`chemical.gaussian_frequency@1` 检查没有错误标记的正常终止，
以及全部为有限数值的频率表中恰好一个负频率，
不能单独认证过渡态。[专用路径验证器](../../candidate-generation/references/gaussian_path.zh-CN.md)
具有额外的拓扑和输入约束，只适用于该参考明确说明的体系。其他体系使用原始输出与
适合当前反应的分析脚本完成上述检查，不需要套用专用验收 profile。

核验元素计数、原子 mapping、电荷、多重度、电子态、关键距离与二面角、立体化学，并确认
没有意外片段或构象变化。将 SCF 不稳定、自旋污染、态歧义、方法敏感性与缺失稳健性检查
作为不同问题处理。

把每个已核验属性记录为研究记录，并引用主要输出与分析 Artifact。缺失、冲突或歧义
证据记录为研究记录。这些记录为之后的状态决策提供信息，但不会自动改变研究 Node 或
假设。IRC 连通性是独立验证维度，由 `irc` 处理。
