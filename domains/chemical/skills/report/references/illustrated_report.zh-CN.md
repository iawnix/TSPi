# 图表与报告制作

## 内容与数据

开头回答研究问题，然后解释方法、关键结果、证据强度、缺失数据和后续建议。
保留用户要求的比较对象，包括失败和未完成任务，不把缺失值记为零。
从实际结果建立 CSV/JSON 数据表，至少包含结构/状态标签、方法/基组、溶剂、电荷/多重度、
能量类型与单位、验证状态、源文件或 Artifact 引用。涉及热力学量时记录温度、标准态和修正方案。
记录原始文件摘要及绘图使用的具体字段，保留绘图脚本。

## 选择图表

| 证据 | 推荐展示 | 必要标注 |
| --- | --- | --- |
| 反应物、中间体、候选过渡态、产物几何 | 分子结构图或多面板对比 | 结构标签、关键原子编号/距离、验证状态 |
| 同一基准下的多个驻点能量 | 相对能量剖面 | 零点、能量类型、单位、方法和已验证连接 |
| 坐标扫描或 IRC 点列 | 能量对反应坐标的曲线 | 坐标定义及单位、方向、收敛与缺失点 |
| 方法或构象比较 | 数值表、点图或柱图 | 比较口径、相对基准、方法/环境 |
| 频率或动力学分析 | 频谱、时间序列或轨迹快照 | 频率/时间单位、采样范围、原始数据来源 |

使用实际分子坐标生成分子图。复杂反应可增加反应示意图或研究流程图，但应清楚区分示意图和计算证据。
环境名称只是计算位置；不能把不同机器作为不同科学方法来解释。

## 能量曲线

同一可比组内计算 `ΔE_i = E_i - E_ref`；Hartree 转为 kJ/mol 时乘以 `2625.49964`，
转为 kcal/mol 时乘以 `627.50947`。保留原始值，标明参照态。
电子能、含零点修正能、焓和 Gibbs 自由能分别列出，不能混接为一条曲线。
只有满足相同组成/化学计量、方法、电子态和热力学条件的数值才直接比较；
分子数不同的反应基准需按化学计量求和并说明标准态处理。不同方法分别设置自身参照。

驻点剖面使用离散能级或明确标为示意的连线，不能将其绘成经过计算的连续路径。
只有实际扫描或 IRC 数据才按真实坐标绘制路径曲线；不要用插值掩盖失败点。
未验证的候选用空心点、虚线或文字标注，不把它标为已确认 TS；有重复或误差证据时才绘制误差条。
有实际路径连通证据才能声称两个驻点相连。无可比数据时说明缺项，提供已有表格，不伪造曲线。

## 制作与核验

在报告目录保存 `data/`、`figures/` 和绘图脚本。使用目标环境可用的 Matplotlib 等绘图库生成
SVG/PNG；保存数值数据便于复算。绘图属于报告整理，不需要新增科学 executor；需要受管环境时使用通用 Job。
不要假设最小 Host Python 已安装科学绘图库。

正文使用 Markdown 图片语法嵌入相对路径（如 `figures/energy-profile.svg`），随后给出
图号、参照态、方法、关键解释与来源引用。图内文字须可读，单位和图例完整，配色兼顾灰度辨识。
表格保留合理有效数字；图与表共享同一数据源。

导出后打开文档和各张图，检查图片是否实际显示、分页/裁切、字体、图注、链接、数值及来源是否一致。
登记最终文档、图片、数据表和脚本，保留相对目录结构供离线阅读。
若格式转换工具缺失，明确说明实际交付格式，不能声称已生成未生成的 PDF/HTML。
