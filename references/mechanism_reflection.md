# Mechanism Reflection

Mechanism reasoning is hypothesis management, not a hidden state machine.

Use endpoint composition, atom mapping, reaction-center changes, charge,
multiplicity, and known chemistry to state a testable hypothesis. Record what
must be observed for the current phase to be supported or refuted.

When evidence contradicts the hypothesis, close the node with the program facts,
the scientific verdict, the implication, and open questions. Then open a new
branch with the changed variable made explicit.
