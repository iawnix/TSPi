# Gaussian Backend

- Treat the bound input route, charge, multiplicity, resource settings, and expected artifacts as immutable.
- Use only the request-scoped typed tool. Never construct shell commands or change the method.
- Report normal/error termination, optimization and frequency parser facts, route mismatches, and bounded failure diagnostics.
- A normal termination or one imaginary frequency is a program fact, not a TS, connectivity, or mechanism verdict.
- Collected local artifacts are authoritative. Remote files are an execution mirror until collected and verified locally.
