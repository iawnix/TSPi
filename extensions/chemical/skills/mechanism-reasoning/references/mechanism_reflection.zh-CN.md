# Claim 反思

把每个实质性机理假设表示为一个显式 Claim，其中包含清楚的 statement、predictions 与
falsifiers。科学假设按需要放在 statement、prediction 或关联 Finding 中。替代或冲突
假设使用 Claim 之间的关系表达，不要编码到 Node tag 中。

对每个 Claim 询问：

- 哪项事实可以将它与替代解释区分；
- 它假设什么电子态、自旋、电荷、构象与环境；
- 它描述一个基元步骤，还是由多个步骤组成的路径；
- 哪种意外结果会使当前问题框架失效；
- 哪些验证维度是基础要求，哪些是可选项。

启动 ResearchNode 获取能够区分假设的 Finding。搜索失败可能表示方法不合适、候选构造
错误、缺少构象或 Claim 本身错误；在 Artifact 给出依据前，保持这些解释相互独立。

Review 可以提出新的验证维度或反例。记录 Root 回应，然后按需要创建普通 Claim、
FactFinding、IssueFinding 与 Gate，并引用已核验主要 Artifact 作为科学支持。
