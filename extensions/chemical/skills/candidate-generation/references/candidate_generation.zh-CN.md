# 候选生成

候选生成用于创建后续过渡态优化和表征的结构。

## Root 选择

在化学启发构造、受限扫描、QST2/QST3、直接 TS 优化、NEB/路径插值、构象搜索、片段接近
采样或其他有依据的方法之间选择。根据当前假设与证据决定使用顺序。

QST2/QST3 前，核验原子数量/顺序或显式 mapping、电荷/自旋、已优化且兼容的端点、构象
兼容性，并确认两个结构描述同一个基元步骤。记录为什么该插值能够检验所提出的步骤。

## 记录

创建 ResearchNode，并在 objective 中说明候选检验的假设。所有 seed 都通过逻辑 Artifact
ID 绑定。关联每个不可变 compute intent，并保留方法/参数。收集后，在有用时把候选坐标、
能量、约束与来源记录为不同 Finding。

畸变几何、原子映射歧义、片段塌陷、意外成键、电子态问题或缺失构象也使用 Finding 记录。

## 后续工作

候选仍需科学上适当的优化与表征。对经典 TS，通常要分别记录：

- 驻点/收敛 FactFinding；
- 虚频模式/反应坐标归属 Finding；
- 双向连通性与端点 identity Finding；
- 其他电子态、稳健性、立体化学或热化学检查。

只有完成或比较标准需要可见 verdict 时才创建 Gate。把替代候选或方法记录为分支，并在
选择下一步时比较其 Finding。
