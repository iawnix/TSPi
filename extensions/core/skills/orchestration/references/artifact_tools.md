# Artifact tools

Use the registered tool schemas as the parameter contract. `artifact_create` stores supplied content; `artifact_register` registers an existing workspace file, optionally bound to its producer Job and Node. `artifact_read` reads registered evidence. `artifact_link` persists the relation to a Claim, Finding or Gate.

`artifact_derive` records a derivation descriptor only; it does not execute an analysis or generate scientific results. Run structure generation, comparison, parsing or report building through the relevant Skill scripts and generic Job Runtime, then register the actual outputs. No analysis capability catalog is required.

Inspect content, digest, producer and units before citing an Artifact. Registering a file does not establish convergence or support a Claim. Record those conclusions through Research State using the Skill's validation criteria.
